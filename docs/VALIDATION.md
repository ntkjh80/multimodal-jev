# 검증 기록

검증 환경: macOS / Python 3.9.6 / 2026-10-25.
**가상환경에서 30개 테스트 통과** (`Ran 30 tests in 2.626s · OK`).
실제 API 키나 CUDA 모델은 사용하지 않았습니다.

## 수행한 검증

- Python 표준 라이브러리만으로 가상환경 생성.
- `python -B -m unittest discover -s tests -v`로 회귀 테스트 실행.
- 정답·태그·그룹 정보가 추론 입력에 포함되지 않는지 확인.
- 불완전한 확률분포, NaN, 입력 잘림 표시, 미제공 토큰 처리 확인.
- JSONL/CSV 가져오기, 미디어 참조, WAV 업로드와 HTTP Range 응답 확인.
- 실제 HTTP 요청 파서로 Host·Origin·세션 토큰 검증, 정적 파일·내보내기 응답 확인.
- 반복과 워밍업 분리, 설정 스냅샷, 중단 후 재개 및 관측치 중복 방지 확인.
- 알려진 정답으로 Accuracy/F1/Brier/ECE 계산 확인.
- JavaScript 문법 검사.
- 실제 데모 결과를 사용한 8개 화면 경로의 렌더링 코드 실행 확인.
- 전체 Python AST 검사와 SVG XML 파싱, CSS 재정렬 전후 내용 동일성 확인.

화면 경로 검사는 최소 DOM 대역으로 HTML 생성 코드를 실행한 것입니다.
실제 브라우저 렌더링, 클릭, 반응형 배치 검증을 대체하지 않습니다.

HTTP 테스트는 실제 BaseHTTPRequestHandler에 직렬화된 요청을 전달합니다.
포트에 소켓을 바인딩하지 않으므로 실제 브라우저와 서버 사이의 통신을 검증한 것은 아닙니다.

## 현재 환경에서 수행하지 못한 검증

| 항목 | 상태 / 이유 |
|---|---|
| 실행 서버와 브라우저의 전체 흐름 | 로컬 포트 바인딩이 실행 환경 권한으로 차단됨 |
| 실제 화면 캡처·레이아웃 확인 | 브라우저 정책이 로컬 파일 URL을 허용하지 않음 |
| Windows 실제 실행 | Windows 호스트가 없음. 실행 스크립트와 CI 매트릭스 제공 |
| GitHub Actions 실행 | 원격 저장소에 올리기 전이므로 실행하지 않음 |
| TypeSafe·Cloudflare·Ollama 실제 추론 | 키·설치된 모델을 사용하지 않음. 규약과 모의 응답으로 검사 |
| Jev-Omni GPU worker | CUDA·모델 가중치 미설치. 실제 로딩·메모리·속도는 미검증 |

이 문서의 테스트 결과는 앱의 동작 검증이며 모델 성능 비교 결과가 아닙니다.
특히 선택형 GPU worker는 검토한 checkpoint revision과 호환 패키지로 별도 검증해야 합니다.
공식 Python 모듈의 내부 결정 헤드 인터페이스를 사용하므로 revision 변경 시 재검증이 필요합니다.

## 사용자 환경에서 확인할 순서

1. README의 Windows 또는 macOS 명령으로 실행합니다.
2. 브라우저에서 `http://127.0.0.1:8766`을 열고 데모 실험을 실행합니다.
3. 데이터셋을 직접 만들고 이미지·WAV·짧은 MP4를 각각 연결합니다.
4. 선택한 실제 모델을 샘플 1개로 먼저 실행해 입력 지원과 토큰 보고 여부를 확인합니다.
5. 같은 데이터셋으로 모델 2개를 비교한 뒤 동시 요청·반복을 늘립니다.
6. 중단·재개, CSV/JSON 내보내기, 앱 재시작 후 기록 유지를 확인합니다.
7. GitHub에 push한 뒤 운영체제별 Actions 결과를 확인합니다.

외부 API 호출에는 설정한 제공자의 비용이 발생할 수 있습니다.
